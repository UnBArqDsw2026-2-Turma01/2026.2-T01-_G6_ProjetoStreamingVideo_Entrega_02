## Pauta

1. Alinhamento das diretrizes da Entrega 2 e organização das subequipes;
2. Escolha da tecnologia de referência para a elaboração dos diagramas UML;

## Discussão

### 1. Alinhamento das diretrizes da Entrega 2

Primeiramente, realizou-se um alinhamento geral a respeito das demandas solicitadas na Entrega 2, referentes aos diagramas estático e dinâmico conforme padrão UML, a serem entregues por cada subequipe. Nesse sentido, todos ficaram cientes acerca do trabalho a ser realizado até quinta-feira (17/09/2026), quando todas as subequipes se reunião novamente para revisar as entregas produzidas por cada uma e realizar os ajustes que forem necessários para a entrega final.

### 2. Divisão do trabalho entre as subequipes

Em seguida, discutiu-se sobre os módulos da aplicação de referência que cada subequipe ficaria responsável por apresentar nos diagramas. Nesse ponto, mantiveram-se os mesmos módulos por subequipe que foram definidos para a Entrega 1:

- Subequipe 1: Transmissão ao vivo, User Generated Content, Clipagem;
- Subequipe 2: Chat ao vivo, Monetização~;
- Subequipe 3: Autenticação, Telemetria, Moderação

### 3. Definição da tecnologia de referência

Ao final, discutiu-se sobre qual tecnologia (linguagem de programação) as subequipes deveriam se basear para a elaboração dos diagramas. A tecnologia definida em consenso por todos foi a linguagem de programação TypeScript.

## Decisões

| # | Decisão | Justificativa |
| -- | -- | -- |
| D01 | Dividir módulos entre as subequipes da mesma maneira que foi feita a divisão na Entrega 1 | Maior familiaridade para desenvolver os diagramas com módulos já estudados anteriormente |
| D03 | Adotar como tecnologia de referência para desenvolvimento dos diagramas UML a linguagem de programação TypeScript | Padronizar referências a um tipo de codificação nos diagramas | 
| D04 | Produzir, cada subequipe, a entrega respectiva até quinta-feira (17/09/2026) para revisão e ajustes finais | Permitir tempo disponível para revisão e ajustes |
