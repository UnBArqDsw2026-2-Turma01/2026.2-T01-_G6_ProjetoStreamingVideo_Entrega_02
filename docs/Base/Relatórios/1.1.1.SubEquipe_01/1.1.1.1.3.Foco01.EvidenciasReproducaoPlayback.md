# Evidências — Reprodução / Playback

Esta página registra o fundamento do componente de Reprodução/Playback. As imagens originais permanecem na página [Evidências do Diagrama de Classes](1.1.1.1.1.Foco01.Evidencias.md) e não são duplicadas.

## E9 — variantes de qualidade

**Fonte:** RFC 8216, atributo `EXT-X-STREAM-INF`.

**Implicação no UML:** `QualityVariant` registra `resolution`, `bitrateBps`, `framesPerSecond` e `audioOnly`; `MediaManifest` oferece uma ou mais variantes.

## E10 — duração-alvo e sequência

**Fonte:** RFC 8216, tags `EXT-X-TARGETDURATION` e `EXT-X-MEDIA-SEQUENCE`.

**Implicação no UML:** `MediaManifest.targetDurationSeconds` é obrigatório e `VideoSegment.sequenceNumber` identifica a posição do segmento.

## E11 — manifesto mestre capturado

**Fonte:** manifesto HLS público capturado no navegador e registrado como E11.

**Implicação no UML:** confirma com dados reais a URI das variantes e os atributos de resolução, bitrate e taxa de quadros.

## E12 — playlist de mídia capturada

**Fonte:** playlist HLS pública capturada no navegador e registrada como E12.

**Implicação no UML:** confirma `VideoSegment.sequenceNumber`, `durationSeconds` e `uri`, além da relação entre variante e segmentos.

## Decisões de projeto declaradas

| Decisão | Justificativa | Limite |
| -- | -- | -- |
| `PlaybackSession` mantém live, espectador, variante e buffer | Reúne o estado necessário para acompanhar uma reprodução | A implementação real do player não foi observada |
| `PlaybackToken` tem validade e resolução máxima opcional | Explicita autorização temporária sem acoplar a sessão à política externa | O token real da plataforma não foi capturado |
| `selectVariant(variantId)` recebe uma variante existente | Evita introduzir o tipo não definido `NetworkMetrics` | A estratégia adaptativa permanece fora do modelo estático |
| `User` é opcional na sessão | Permite reprodução anônima sem inventar um usuário persistido | Política de acesso anônimo deve ser confirmada pelo produto |

## Matriz de revisão

| Evidência | Elementos revisados | Resultado |
| -- | -- | -- |
| E9 | `QualityVariant`, composição `MediaManifest → QualityVariant` | Variantes normatizadas representadas |
| E10 | `targetDurationSeconds`, `sequenceNumber` | Ordenação e duração-alvo representadas |
| E11 | `uri`, `resolution`, `bitrateBps`, `framesPerSecond`, `audioOnly` | Atributos confirmados em manifesto real |
| E12 | `VideoSegment`, composição `QualityVariant → VideoSegment` | Segmentos reais representados |
| Decisão de projeto | `PlaybackSession`, `PlaybackToken`, autorização e seleção | Inferências identificadas sem tratá-las como observação |
